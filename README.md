# Agentic YouTube Summary

[English](README.md) | [中文](README.zh.md)

---

**Agentic YouTube Summary** is an automated workflow designed to download YouTube subtitles, clean scrolling transcript noise, and generate structured AI summaries. 

It can be used as a standalone command-line tool or integrated seamlessly into AI coding assistants (**Cursor**, **Claude Code**, **Cline**, **Windsurf**, and **Claude Desktop**) via the Model Context Protocol (MCP)—allowing users to analyze and summarize videos directly through natural language chat.

---

### 🌟 Primary Use Cases

- **Fast Video Content Digestion**: Extract core takeaways, structured outlines, and key insights from long tutorials, tech talks, educational lectures, or podcasts without watching the entire video.
- **Multilingual Support**: Seamlessly process both English and Chinese YouTube content with language-matching summary output.
- **Conversational Workflow**: Trigger end-to-end video analysis directly inside your AI coding assistant workspace using plain commands like *"Summarize this video: <URL>"*.

---

### ✨ Key Features

- **Automated Transcript Extraction**: Downloads official or auto-generated subtitle tracks with automatic failover handling.
- **Smart Text Deduplication**: Filters out WebVTT/SRT tags and eliminates repetitive scrolling text generated by live auto-captions, outputting clean, readable paragraphs.
- **Structured Markdown Summaries**: Generates comprehensive summaries containing an executive overview, core key takeaways, and section-by-section breakdown.
- **Iterative Quality Verification**: Evaluates summary drafts on accuracy, completeness, and conciseness, automatically refining content before finalizing output.
- **Flexible Execution Modes**:
  - **API Direct Mode**: Automatically calls Gemini API to produce structured summary documents.
  - **Agent-Cooperative Mode**: Cleans the transcript and allows your AI Coding Assistant to generate summaries directly in chat without requiring API keys.

### 🛠️ Getting Started

#### 1. System Requirements
This tool requires `ffmpeg` for media handling.
- **macOS**: `brew install ffmpeg`
- **Ubuntu/Debian**: `sudo apt update && sudo apt install ffmpeg`

#### 2. Installation
```bash
pip install -r requirements.txt
```

#### 3. Configuration
Copy `.env.example` to `.env` and set your API key:
```ini
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-1.5-flash
```

---

### 💻 Usage

#### Command Line Interface (CLI)
Process one or multiple YouTube URLs:
```bash
python main.py "https://www.youtube.com/watch?v=PDZf7EiKwyw"
```

- **Cleaned Transcript**: Saved to `storage/transcripts/`
- **Summary Report**: Saved to `storage/metadata/`

#### AI Assistant Integration (MCP)
Add `mcp_server.py` to your AI Assistant's MCP configuration:

```json
{
  "mcpServers": {
    "youtube-summary": {
      "command": "python3",
      "args": [
        "/absolute/path/to/youtube_processor/mcp_server.py"
      ],
      "env": {
        "GEMINI_API_KEY": "your_api_key_here"
      }
    }
  }
}
```

For detailed agent setup instructions, see [**AGENT_INTEGRATION.md**](AGENT_INTEGRATION.md).
